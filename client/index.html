Carreras 2D en tiempo real

Ponle acento paisa, rolo o costeño a tus vueltas — pistas con sabor colombiano, karts sin fronteras.

Cómo jugar

  • W / S para acelerar / frenar, A / D para girar (también sirven las flechas). C cambia la cámara y Esc (o el botón ⏸) pausa la carrera para todos. O usa un control PS4/Xbox conectado: stick para girar, R2/X para acelerar, L2/Cuadrado para frenar, Options/Start para pausar.
  • Completa 3 vueltas pasando por los puntos de control en orden.
  • Si faltan jugadores, actívalo en el lobby: la sala se completa con bots hasta tener una carrera decente, con la dificultad que elijas.
  • Recoge tinto, arepa, aguapanela y otras delicias para un boost de velocidad.
  • Elige la pista en el lobby: cada región de Colombia tiene su propio trazado.
  • El servidor decide la posición real de cada kart: lo que ves ya fue validado por él.
